# 캔바 교실 스토리 (웹 슬라이드)

캔바 활용 교사 연수용 스토리형 웹 슬라이드 26장. `index.html` 파일 하나로 동작하며, 폰트(Pretendard 부분 글꼴)를 파일 안에 넣어 두어 인터넷 없이도 열 수 있습니다.

## 발표 조작
- 넘기기: ←/→ 키, Space, 클릭(화면 왼쪽 1/4은 이전), 터치 스와이프
- 전체화면: 오른쪽 위 `전체화면` 버튼 또는 `F` 키
- 특정 슬라이드 바로 열기: 주소 끝에 `#8`

## 발표 전에 바꿀 것
`index.html` 맨 아래 `CONFIG`:
- `demoVideoUrl`: 시연 영상 주소를 넣으면 21번 슬라이드에 영상 버튼이 생깁니다.
- `showExampleTags`: 3·8·24번 슬라이드 숫자는 **예시 수치**입니다. 사전 설문이나 직접 잰 값으로 바꾼 뒤 `false`로 두면 "예시 수치" 표시가 사라집니다.

## 수정과 다시 만들기
`src/slides.src.html`을 고친 뒤 `src` 폴더에서 `python3 build_html.py ../index.html <PretendardVariable.woff2 경로>`를 실행합니다(fonttools, brotli 필요, 폰트는 npm `pretendard` 패키지의 `dist/web/variable/woff2`에 있음). 새 글자를 넣고 다시 빌드하지 않으면 그 글자만 시스템 폰트로 보입니다.

폴더째 Vercel에 올리거나 `index.html`을 아무 정적 호스팅에 올리면 됩니다.
